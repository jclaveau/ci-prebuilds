# ── Form-control subcluster ───────────────────────────────────────────────
# Root-caused 2026-06-26: Alpine's community/chromium apk ships
# chromium-headless-shell with the UA stylesheet defaulting form controls
# to `appearance: none`. Vanilla checkbox renders 0px wide; vanilla range
# renders 0px tall — both fail PW's auto-wait `is visible` check. Confirmed
# via debug/probe-visibility-cluster.cjs (injecting `appearance: auto
# !important` un-breaks the checkbox). Not fixable without a chromium
# build patch / different apk.
#
# See .agents/auto-memory/project_pw_conformance_visibility_cluster.md.
tests/page/page-check\.spec\.ts$
