# capabilities "should not crash on showDirectoryPicker": PW's own test comment

# can't be dismissed, so the pending picker blocks context.close → "Test ended".
# A headed-Xvfb-no-WM limitation, not a crash (the test's own name/intent is
# "should not crash", and it does not). Upstream issue microsoft/playwright#7339.

# headed-only, an upstream test-fragility (it already `it.fail`s this same test
# for firefox, microsoft/playwright#38919) — not a timezone/worker browser bug.
