# Format: one PW test full-title regex per line. Blank lines + lines starting
# with `#` are ignored. Joined with `|` into a single `--grep-invert` pattern.
# Test full-title example:
#   "[chromium-library] › tests/library/foo.spec.ts:10:5 › some title"
# Patterns are matched against this string, so a path fragment like
# `tests/library/inspector/` skips every test under that directory.

# for a reason that cannot be fixed in the artifact. Each entry tags one of:

#                that need a UI subsystem (trace viewer, codegen recorder,
#                video pipeline, OOPIFs, pause/debugger) cannot pass.
#   ALPINE     — real Alpine/musl conformance gap, tracks to umbrella.
#   UPSTREAM   — waiting on microsoft/playwright fix.
