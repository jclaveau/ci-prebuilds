# Prior "recorder-dependent" file skips (inspector/*, selector-generator,
# trace-viewer*, debug-controller, slowmo) were REMOVED after diagnosing the
# root cause: PW's recorder subsystem launches an INTERNAL headed chromium
# as its UI harness, decoupled from the browser under test. The runner
# image now bundles `chromium` + `xvfb-run` (see conformance/build-runner.sh)
# and the `xvfb-run -a` wrap in run.sh gives the harness an X server —
# ~453 tests recovered.

# Prior client-certificates + proxy stack file-skips REMOVED after diagnosing
# the root cause (agent 3, 2026-07-09): Alpine FF build was missing PW's
# `00-playwright-prefs.js` + `playwright.cfg` at the correct dist paths
# (Ubuntu FF ships them there). Missing prefs meant `dom.security.https_first`
# stayed on, PW's proxy filter never attached, and every proxied navigation
# broke. Fixed both at BUILD time (`firefox/scripts/apply-and-build.sh` post-
# build DIST copy) AND at RUNNER-image time (`conformance/build-runner.sh`
# curls the prefs into the FF dist) so pre-built artifacts also benefit.
# Recovers ~56 tests: client-certs (45) + proxy.spec.ts (11) + likely
# browsercontext-proxy / -cookies-third-party / -reuse siblings.
