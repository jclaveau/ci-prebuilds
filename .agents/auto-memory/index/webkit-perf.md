- [musl's fmod is all of libm_fmod, and the rewrite ships gated](project_wk_fastfmod_ships.md) — glibc 54 ms / musl 164 ms per 3M; a branchless drop-in preloaded beside mimalloc takes the kernel 289.6→122.7; the CI gate diffs raw result bits over 7.5M pairs and caught a NaN-SIGN bug on its first run (PR #131, issue #126); #167/#170 then replaced the bit loop with glibc's own tzcnt-strip + chunked divide (do NOT re-derive it); the RATIO is a measurement, not a runner fingerprint (9V74 1.12 non-overlapping, 7763 0.93/0.96 — our arm flat, official's moves) and the residual is a TRANSFER gap: isolated 0.91x vs in-browser 1.12x on the same core class, so profile the WebProcess instead of writing another candidate; RESOLVED per-microarchitecture — profiled per round, the shim is 0.92-0.94 on EPYC 7763 (n=3) and 1.16 on EPYC 9V74 (n=1) while JIT stays at parity on both, so the row IS ours-vs-glibc; both gain on Zen 4 (ours 1.30x, glibc 1.52x) and WHICH instruction glibc stops paying for is the only open thread
